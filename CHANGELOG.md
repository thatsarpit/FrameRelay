# Changelog

## 0.1.0 — 10 October 2026

First source preview: native studio/menu bar, private-LAN RTMP receiver, optional stream-copy recording/audio, local MP4 finalization, preview-only mode, reconnect, disk reserve and opt-in startup. Credential-free RTSP input is implemented but not hardware tested.

Modern camera-extension and host bridge compile, with a developer signing script and explicit pending-runtime status. Default receiver builds do not include an installable virtual camera. No notarized binary release.
